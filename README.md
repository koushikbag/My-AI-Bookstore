# My-AI-Bookstore

This repository now contains a starter Flutter project for the bookstore application.

## Getting Started

1. Install Flutter: https://docs.flutter.dev/get-started/install
2. From the repository root, get dependencies:
   ```bash
   flutter pub get
   ```
3. Run the app:
   ```bash
   flutter run
   ```
4. Run tests:
   ```bash
   flutter test
   ```
